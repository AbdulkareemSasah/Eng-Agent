# Calc verification records

Each calc has `<calc id>.md` here (status draft until the owner approves, spec 0003 section 4.5). Template:

- Calc id, version and content hash (from `calcs.lock.json`)
- Status: draft
- Method source: the spec section and rules
- Golden cases: file, method rule, hand derivation, result
- Boundary and property tests: test ids
- Reviewer and date
- Findings and open gaps
