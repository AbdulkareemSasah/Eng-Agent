# Changelog

## Unreleased

- Calc kinds: `eng_harness.kinds.calcs` (the six calc payloads, `harness.expected_effects/1`, `CalcMeta`) registered in `eng_harness._kinds`; `kinds/**` added to the R2 modules (plan 0003 T4, B-143; spec 0003 AC47).
- Template repository and checker: `TemplateRepository` (shipped and user folders, `TemplateAmbiguous`, synthetic refusal unless `allow_synthetic`), `load_template`, and `check_template` with `TemplateReport` listing every error and warning without raising; `resolve` and its types exported from `eng_harness.templates` (B-158; spec 0004 AC12, AC13).
- Process transport and MCP client session: `ServerManager` (lazy role start, uncached complete tool list, raw calls with the client backstop, crash detection, restart with re-attach by process id within `max_restarts_per_run`, session epoch, shutdown that leaves host instances) over `ProcessTransport`, which speaks MCP over the pipes of a harness-launched process; `CallEffect` decides `HOST_NOT_CONNECTED`, `TIMEOUT_NO_EFFECT` or `TIMEOUT_UNKNOWN_OUTCOME` for a lost call (plan 0002 T5, B-124; spec 0002 AC8, AC11, AC12). The build check after each start follows in T6b.
- Template inheritance: `eng_harness.templates._resolve.resolve` follows `meta.extends` (exact pin, depth at most 8, cycles refused), merges per the spec rules, refuses an ask path that is repeated or has a value, and computes the resolved `sha256` over the chain and the canonical model (B-157; spec 0004 AC8 to AC11).
- Strict YAML 1.2 loader `eng_harness.templates._yaml` (`load_strict`, `loads_strict`): refuses duplicate keys, anchors, aliases, tags, non-string keys, non-finite numbers, more than one document, files over 1 MiB and nesting deeper than 8; `ruamel-yaml>=0.19,<0.20` runtime dependency with ADR-0004 (Proposed) (B-156; spec 0004 AC7).
- Calc-module rules test (imports, purity, module state, FB005 forms), golden data loader and file lint, and the verification record template (plan 0003 T6, B-145; spec 0003 AC3, AC46).
- Journal event payload models: `eng_harness.journal` (the 21 event types and `PAYLOAD_MODELS`) and the harness result kinds in `eng_harness._kinds` (plan 0001 T3, B-102).
- Calc framework: `eng_harness.calc` (decorator, registry with the AC1 registration rules, input metadata, trace builder, statuses) and the empty `eng_harness.calcs.REGISTRY`; `calcs/**` added to the R1 modules (plan 0003 T1, B-140).
- Harness codes and the EngineStop, StepError, RunRefused, RunLocked and JournalIntegrityError families (B-101).
- Package skeleton: `pyproject.toml` with the gate configuration, workspace member, `__version__`, `py.typed`, README, rendered `AGENTS.md` and risk map (B-100).
- Servers configuration: `eng_harness.servers` loads and validates the `[servers.*]`, `[cli_tools.*]` and `[host_programs.*]` sections of `harness.toml` (required timeouts, forbidden options); `mcp>=2.3,<3` runtime dependency with ADR-0001 (Proposed) (B-120).
- Synthetic Sasaah CSI fake server (test-only, `tests/fakes/sasaah_csi/`), its schema copy of the S-12 inventory, the contract test that keeps them equal and the packaging test that proves tests are not shipped (B-123).
- Process launcher and inspector ports with the POSIX implementation (process group per server, `/proc` identity with the boot id, pidfd-checked terminate): `eng_harness.servers._launcher` and `._procinfo`; the Windows launcher follows in T3 (B-121).
- Windows launcher and inspector: `eng_harness.servers._launcher_windows` starts each process suspended in a Job Object of its own (kill-on-close; silent breakaway for servers, none for tools), assigns it and then resumes it, and `WindowsProcessInspector` in `._procinfo` identifies and ends processes by pid and creation time on one handle; both run over a kernel32 object with a fake; the fake-based tests in `tests/windows` run on every platform, and the tests that start real processes have not run on Windows yet (owner local test, `docs/local-testing.md` item 13) (B-122).
- Template model: `Template`, `Meta`, `Entry`, `Bounds`, `AskItem` and `TemplateInvalid` with citation, canonical-unit, finiteness and bounds rules (B-155; spec 0004 AC1 to AC6).
- Text, date and number formatting and sanitizing: `eng_harness._text` and its culture-invariance rule test (B-175).
- HTML builder: `eng_harness._html` (text escaped by construction, safe tokens, labeled untrusted `<bdi>` fields, style element with its SHA-256 policy source) and the shared style sheet `eng_harness.pages._css` (B-176).
- Report package skeleton: `eng_harness.report` with `ReleaseMarks`, `ReportError` and `unreleased_dependencies` (breadth-first lineage closure over `parents` and provenance inputs, depth limit) (B-182).
- Command line shell: `eng_harness.cli` with `main`, parser of the six commands (no approve command), exit codes, `harness.toml` sections, output encoding, `eng-harness` script and `python -m eng_harness` (B-177).
