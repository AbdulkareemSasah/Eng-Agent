## 1. What this check verifies (in our own words)

For a short, rectangular, nonprestressed column section with a symmetric bar arrangement, under a factored axial
compression and a factored moment about one principal axis, the check finds the design strength point on the
axial-moment interaction diagram that lies on the line from the origin through the demand point (constant
eccentricity), and compares the demand moment with the moment of that point. The diagram is built by strain
compatibility with the rectangular concrete stress block, an elastic-perfectly plastic steel model, the strength
reduction factor as a function of the net tensile strain, and the cap on the axial design strength. A verdict is
produced only for uniaxial bending; biaxial bending, axial tension and slender columns return `NEEDS_ENGINEER`.

## 4. Method

### 4.1 Shared section model (CS)

- **CS S1 Layout.** `Ast = A_bar·(2·n_bars_b + 2·n_bars_h − 4)`; `Ag = b·h`. Bar layers `j = 0 … n_bars_h − 1` at depth
  `d_j = d' + j·(h − 2·d')/(n_bars_h − 1)` from the compression face; area `A_j = n_bars_b·A_bar` for the two outer
  layers and `2·A_bar` for the others. The arrangement is symmetric about mid-depth.
- **CS S2 Material.** `εty = fy/Es` (21.2.2.1; the permission to take `0.002` for Grade 420 is not used); steel stress
  `fs = Es·εs` for `|εs| < εty`, else `±fy` (20.2.2.1); `β1` from Table 22.2.2.4.3 (rows as in the flexure spec of plan
  0002); concrete tensile strength neglected (22.2.2.2).
- **CS S3 Section forces for a neutral-axis depth `c > 0`** (22.2.1 strain compatibility, linear strain, 22.2.2.1
  `εcu`): `a = min(β1·c, h)`; concrete `Cc = α1·fc·a·b` (22.2.2.4.1) acting at `a/2`; layer strain
  `ε_j = εcu·(c − d_j)/c` (compression positive); layer force `F_j = A_j·(fs_j − α1·fc)` when `d_j < a` (bar inside the
  stress block: the displaced concrete is removed, consistent with `Ag − Ast` in Eq. 22.4.2.2; C-3), else
  `F_j = A_j·fs_j`. `Pn(c) = Cc + Σ F_j`; `Mn(c) = Cc·(h/2 − a/2) + Σ F_j·(h/2 − d_j)` about mid-depth.
- **CS S4 Net tensile strain** at the extreme layer `dt = h − d'`: `εt = εcu·(dt − c)/c` (tension positive).
- **CS S5 Strength reduction** (Table 21.2.1 row (a), Table 21.2.2): with `φ_cc = phi_cc_tied` or `phi_cc_spiral` and
  slope `s = phi_tr_tied` or `phi_tr_spiral` by `transverse_kind`: `φ = φ_cc` when `εt <= εty`;
  `φ = phi_tc` when `εt >= eps_tc`; otherwise `φ = φ_cc + s·(εt − εty)/(eps_tc − εty)`.
- **CS S6 Axial cap** (22.4.2.2, Table 22.4.2.1): `Po = α1·fc·(Ag − Ast) + fy·Ast`; `Pn_max = k_max·Po` with
  `k_max = pnmax_tied` or `pnmax_spiral`; `phiPn_max = φ_cc·Pn_max` (uniform compression strain is compression-controlled,
  Table 21.2.2).
- **CS S7 Full-compression depth.** `c_full = max(h/β1, dt·εcu/(εcu − εty))`; at `c_full` every layer has yielded in
  compression and `a = h`, so `Pn = Po` and, by symmetry, `Mn = 0` (both recorded; `εcu > εty` holds because
  `FY_MAX` bounds `fy` below `εcu·Es`).

### 4.2 This check

Units: forces in N and moments in N.mm inside the method; `Pu`, `Mu` converted with `k_kN`, `k_kNm`.

1. Preconditions (§2); CS S1, S2, S6, S7.
2. Demand ray: `g(c) = Mu·Pn(c) − Pu·Mn(c)` is zero where the nominal point lies on the line through the origin and
   `(Mu, Pu)`; `φ` scales `Pn` and `Mn` alike, so the design point lies on the same line.
3. Bracketing (numerical method, C-5): grid `c_i = c_full·i/n_grid`, `i = 1 … n_grid`. Count up-crossings
   (`g(c_i) < 0 <= g(c_(i+1))`) and down-crossings (`g(c_i) >= 0 > g(c_(i+1))`). If `g(c_1) >= 0`, or the number of
   up-crossings is not exactly one, or any down-crossing exists, raise `NotImplementedGap("G-4", ...)`.
4. Bisection on the bracket `[lo, hi]` with `g(lo) < 0 <= g(hi)`: `m = (lo + hi)/2`; replace the end of the same sign;
   stop when `m` equals `lo` or `hi` in float64. No tolerance constant: the search runs to float64 resolution.
5. At each final end, CS S3 to S5 give `φ`, `phiPn = φ·Pn`, `phiMn = φ·Mn`. Capped design moment on the ray:
   if `phiPn > phiPn_max` the ray meets the axial cap and `capM = Mu·phiPn_max/Pu` (`Pu > 0` there); else
   `capM = phiMn`. The end with the smaller `capM` is used (equal for a continuous `g`; the smaller one at a step of
   `Pn` where a layer enters the stress block, CS S3).
6. One verdict: demand `Mu_kNm`, capacity `capM_kNm`. The ratio equals the radial ratio of the demand point to the
   capped diagram.
