## 1. What this check verifies (in our own words)

In each plan direction, the straight length of the bottom bars from the critical section at the column face to the
bar end must be at least the tension development length of a straight deformed bar, computed with the general SI
expression including the confinement term (transverse reinforcement index taken as zero, which the clause permits).
Hooks and the reduction for excess reinforcement are not used.

## 2. Scope and applicability

| Id | Condition | If not met |
|---|---|---|
| (member scope) | Subject kind `footing` | `NOT_APPLICABLE` |
| `NORMALWEIGHT` | `concrete_class` is `normalweight` (19.2.4.2) | `NEEDS_ENGINEER` (gap G-1) |
| `FC_MIN` | `fc_MPa >= fc_min` (Table 19.2.1.1) | `NEEDS_ENGINEER` |
| `FY_MAX` | `fy_MPa <= fy_max` (Table 20.2.2.4(a)) | `NEEDS_ENGINEER` |
| `UNCOATED` | `coating` is `uncoated` | `NEEDS_ENGINEER` (gap G-2: ψe for coated bars, Table 25.4.2.4, not implemented) |
| `ANCHORAGE_POSITIVE` | Available length `la_x > 0` and `la_y > 0` | `NEEDS_ENGINEER` (bar ends do not pass the critical section) |

Assumptions recorded in every verdict: straight bars, no hooks; bottom bars, so the casting-position factor is that of
bars with less than the casting depth limit of fresh concrete below them (Table 25.4.2.4); `Ktr = 0` (25.4.2.3);
size factor `ψs = 1.0` for every bar size (conservative, plan §6 Q10); critical section at the column face
(13.2.7.1); column centered. `FC_MIN` uses the general row of Table 19.2.1.1: the structure is assigned to Seismic Design Category A, B or C, or the footing is a foundation case that the general row covers (C-3, plan §6 Q16).

## 4. Method

Direction X; Y swaps `Lx ↔ Ly`, `cx ↔ cy` and the `_x` inputs for the `_y` inputs.

1. Available straight length beyond the critical section: `la_x = Lx/2 − cx/2 − end_cover` (precondition
   `ANCHORAGE_POSITIVE`).
2. `sf = min(√fc, sf_max)` (25.4.1.4).
3. Factors (Table 25.4.2.4): `ψt = psi_t_bottom`, `ψe = psi_e_uncoated`, `ψs = psi_s_used`; `λ = lambda_nw`.
4. `cb_x = min(cover_x + db_x/2, s_x/2)` (25.4.2.3 definition of `cb`); confinement term
   `conf_x = min((cb_x + Ktr)/db_x, conf_max)` with `Ktr = 0` (25.4.2.3).
5. Development length (eq. 25.4.2.3a, SI): `ld_eq_x = (fy/(c_ld·λ·sf))·(ψt·ψe·ψs/conf_x)·db_x`; the product `ψt·ψe`
   does not exceed `psi_te_max` (25.4.2.4; always met here, recorded).
6. `ld_x = max(ld_eq_x, ld_min)` (25.4.2.1).
7. Two verdicts, X then Y: demand `ld_x_mm`, capacity `la_x_mm`.

## 5. Constants

| Symbol | Value | Unit | Citation |
|---|---|---|---|
| `c_ld` | 1.1 | 1 | ACI 318-14 eq. 25.4.2.3a (SI), coefficient in MPa^0.5 |
| `conf_max` | 2.5 | 1 | ACI 318-14 25.4.2.3 (limit on `(cb + Ktr)/db`) |
| `Ktr` | 0 | mm | ACI 318-14 25.4.2.3 (permitted design simplification) |
| `ld_min` | 300 | mm | ACI 318-14 25.4.2.1(b) |
| `psi_t_bottom` | 1.0 | 1 | ACI 318-14 Table 25.4.2.4 (casting position, other than top bars) |
| `psi_e_uncoated` | 1.0 | 1 | ACI 318-14 Table 25.4.2.4 (uncoated) |
| `psi_s_used` | 1.0 | 1 | ACI 318-14 Table 25.4.2.4 (No. 22 and larger row), used for all sizes (plan §6 Q10) |
| `psi_te_max` | 1.7 | 1 | ACI 318-14 25.4.2.4 (limit on `ψt·ψe`) |
| `lambda_nw` | 1.0 | 1 | ACI 318-14 19.2.4.2 (normalweight concrete) |
| `sf_max` | 8.3 | 1 | ACI 318-14 22.5.3.1, 22.6.3.1, 25.4.1.4 (limit on sqrt f'c) |
| `fc_min` | 17 | MPa | ACI 318-14 Table 19.2.1.1 (minimum f'c, general row) |
| `fy_max` | 550 | MPa | ACI 318-14 Table 20.2.2.4(a) (not special seismic) |
| `c_half` | 2 | 1 | Geometry: bar center at `db/2`; half spacing `s/2`; column face at `c/2` |

Shared constants (B-421): `lambda_nw`, `sf_max`, `fc_min`, `fy_max` are defined once in `aci318_14._common` (plan 0002 §1.1). Their Citation
cell is plain text equal to the constant's recorded `Cited.source`, written identically in every clause spec
that uses it (plan 0002 T2c asserts it).
`sf_max` limits √f'c, so its true unit is MPa^0.5; `UNITS` has no MPa^0.5, so it is stored with unit 1 and
its `Cited.note` reads "true unit MPa^0.5; stored as 1 because the eng-contract unit table has no MPa^0.5
(plan 0002 §6 Q6)". The citation names the three clauses that set the same limit; this check applies the
one of its §4 step.
The coefficient `c_ld` (true unit MPa^0.5) is stored with unit 1 for the same reason; its citation names the
true unit (plan 0002 §6 Q6). The step `sf` is recorded with unit null and its formula names the unit.
`c_half` of this check is its own constant (row above, its own citation text): the check does not run the
footing statics, so the shared `c_half` never enters its trace.
